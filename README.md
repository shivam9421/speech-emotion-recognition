# Speech Emotion Recognition
## Problem Statement 
To detect Human emotion from Audio signal 
## Dataset
RAVDESS — 2880 audio files, 8 emotions
## Approach
- MFCC features → Random Forest
- Mel Spectrogram → CNN (in progress)
- ## Results
| Model | Accuracy |
|-------|----------|
| Random Forest + MFCC | 93% |
| CNN + Mel Spectrogram | Coming soon |
## Tech Stack
Python, Librosa, Scikit-learn, PyTorch
